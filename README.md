# BharatTrip refund reconciliation

Take-home for AI Operations Associate. Phase 1 = data cleaning and reconciliation (plain pandas, no AI).

**Run Phase 1:** `pip install -r requirements.txt && python phase1_analysis.py`

- `recon.py`: cleaning and reconciliation rules (shared with the app in Phase 2)
- `phase1_analysis.py`: runs every analysis and writes `output/`
- `output/phase1_findings.md`: findings summary and assumptions
- `output/phase1_tables.md`: every supporting table
- `output/cleaning_log.csv`, `reconciled_refunds.csv`, `escalations_categorised.csv`, `problem_cases.csv`
